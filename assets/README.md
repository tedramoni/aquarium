# assets/

## music.mp3 (background track)

The site plays `assets/music.mp3` when the 🔇 button is toggled on
(looped, with a gentle fade-in). The file is **not** included in the
repo — add your own here.

Name it exactly `music.mp3`, or change `MUSIC_SRC` at the top of
`../script.js` to match your filename.

### Use a track you're allowed to publish

This site is intended to go on a public GitHub Pages URL, so the audio
is redistributed publicly. Only use audio that permits that:

- **Pixabay** (https://pixabay.com/music/ and /sound-effects/) —
  Pixabay Content License: free, no attribution, redistribution OK.
  Search "whale", "ocean ambient", "underwater".
- **NOAA / National Marine Sanctuaries** ocean sound libraries —
  real whale recordings, US-government public domain.
- **Freesound** (https://freesound.org) — filter the license to **CC0**
  (or CC-BY if you add attribution below).

Avoid ripping audio from YouTube/Spotify: it breaks their terms and
usually redistributes a copyrighted recording without permission.
